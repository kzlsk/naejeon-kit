## 8. 회고

- 잘 된 것: "추가만" 제약 덕분에 운영 DB 적용 전에도 배포 코드가 깨지지 않는 구조가 됐다. PGlite 테스트로 Docker 없이 RPC 권한까지 검증했다.
- 아쉬운 것: 테스트는 마이그레이션 "파일"을 검증할 뿐, 앱이 보는 DB 상태와는 별개라 같은 유형의 오류(`PGRST202`)가 반복됐다.
- 다음: 배포 전 "앱이 보는 DB 에 함수·컬럼이 있는지" 확인하는 점검 단계를 고정한다. 디스코드는 실제 연결 검증 후 "진행 중" 해제.
