# DESIGN.md — 내전 도우미 디자인 핸드오프

> Claude 디자인 캔버스("발로란트 내전 도우미")에서 뽑은 화면 시안을 Next.js 코드로 옮기기 위한 문서.
> 기능·데이터 스펙은 `PRD.md`가 기준이고, 이 문서는 **보이는 모습**만 다룬다. 둘이 충돌하면 PRD가 우선.

## 1. `screens/` 파일 읽는 법

`screens/*.dc.html`은 디자인 캔버스 전용 포맷이라 **그대로 실행되지 않는다.** 레이아웃·색·간격을 참고하는 시안으로만 쓰고, React 컴포넌트로 새로 작성한다.

| 시안 문법 | React로 옮길 때 |
|---|---|
| `<x-dc>` 안의 마크업 | 컴포넌트 JSX |
| `{{accent}}`, `{{m.name}}` | props / state 값 |
| `<sc-for list="{{members}}" as="m">` | `members.map(m => …)` |
| `<sc-if value="{{m.icon}}">` | `{m.icon && …}` |
| `renderVals()` 안의 배열 | **더미 데이터일 뿐** → 실제로는 Supabase 데이터 |
| inline `style="…"` | Tailwind 클래스로 변환 (아래 토큰 사용) |
| `/_blob/...` 이미지 경로 | 캔버스 전용 주소라 외부에서 안 열림 → `public/` 로컬 이미지로 교체 (§5) |
| `<script src="./support.js">`, `data-props` | 무시 |

## 2. 화면 목록 → 라우트 매핑

| 시안 파일 | 화면 | 라우트 / 컴포넌트 |
|---|---|---|
| `Main.dc.html` / `PcMain.dc.html` | 초기 페이지 (방 파기 · 코드 참가) | `/` |
| `Participant.dc.html` / `PcParticipant.dc.html` | 참가자 화면 | `/room/[code]` |
| `MemberForm.dc.html` | 멤버 등록·수정 (내 정보) | 참가자/방장 공용 폼 (모달 또는 시트) |
| `Host.dc.html` / `PcHost.dc.html` | 방장 화면 (멤버 탭 / PC 대시보드) | `/room/[code]/host` |
| `Teams.dc.html` | 팀 짜기 결과 | 방장 화면 "팀" 탭 |
| `MapBan.dc.html` / `PcMapBan.dc.html` | 맵 밴 · 결과 | "맵" 탭 |
| `Side.dc.html` | 공수 결과 + 디코 복사 | "공수" 탭 |

- 모바일 시안: 폭 390px 기준. PC 시안: 1440px, 콘텐츠 `max-width: 1360px`.
- 같은 화면의 모바일/PC는 **하나의 반응형 컴포넌트**로 만든다 (`lg:` 브레이크포인트에서 PC 레이아웃).
- 방장 모바일 화면은 상단 `팀 / 맵 / 공수` 탭, PC는 좌측 멤버 패널 + 우측 팀·맵·공수 카드 대시보드.

### 타이포
- 본문: **IBM Plex Sans KR** (400/500/600/700)
- 방 코드·점수 숫자: **IBM Plex Mono** (500/600), 방 코드는 `letter-spacing: 2px~4px`
- `next/font/google`로 로드
- 크기: 히어로 32px/700 · 화면 제목 17px/600 · 본문 15px · 라벨 13px · 캡션 12px

### 형태
- radius: 버튼·카드 12px, 작은 버튼 8~10px, 큰 카드 14~16px, 칩 999px
- 높이: 주 버튼 56px, 보조 버튼 44px, 작은 버튼 36px, 리스트 행 48~54px
- 화면 좌우 패딩 20px (모바일), 32px (PC)
- **터치 영역 최소 44px** (아이콘 버튼 포함)

## 4. 컴포넌트 패턴

- **주 버튼**: accent 배경 + `#0F1318` 텍스트, 56px, 700. 비활성: `#262D36` 배경 + `#5C6672` 텍스트.
- **보조 버튼**: 투명 배경 + `line-strong` 테두리.
- **탭**: 하단 2px accent 보더가 선택 표시.
- **방 헤더**: 방 코드(Mono) + `방장` 뱃지(accent-soft 배경) 또는 `실시간` 점.
- **멤버 행**: 닉네임 · 티어 아이콘(24px) · 티어 텍스트 · 더보기(⋮). 티어 미입력이면 `정보 미입력`을 danger-text로.
- **티어 선택**: 5열 그리드 아이콘 버튼(티어 그룹) → 3열 단계 버튼(1/2/3). 상단 세그먼트로 `현티 / 최티` 전환.
- **포지션 토글**: 4열 카드, 탭 순환 `가능 → 주력 → 불가`.
  - 가능: `line-strong` 테두리
  - 주력: accent 테두리 + accent-soft 배경 + "주력" 라벨
  - 불가: 점선 테두리 + 취소선 + faint 색
  - 상태를 **색 + 텍스트 라벨**로 같이 표시 (색만으로 구분 금지)
- **팀 카드**: 상단에 팀 색 사각형 + 팀명 + 점수(Mono, 팀 색). 행마다 티어 아이콘·닉네임·추천 포지션(주력은 `· 주력` + 굵게). 경고는 하단 warn 박스.
- **맵 카드**: 맵 이미지 + 어두운 오버레이 + 맵명. 밴되면 grayscale + 반투명 + 취소선 + accent `밴` 뱃지.
- **공수 카드**: 2칸 그리드, 확정된 칸은 accent 테두리 + accent-soft 배경.
- **아이콘**: 인라인 stroke SVG (stroke-width 2). `lucide-react`로 바꿔도 됨. 이모지 아이콘 금지.

## 5. 이미지 에셋

시안의 `/_blob/...` 이미지는 캔버스 안에서만 열리는 주소다. 아래 파일을 `public/`에 직접 넣고 경로를 바꾼다.

```
public/
  tiers/  iron.png bronze.png silver.png gold.png platinum.png
          diamond.png ascendant.png immortal.png radiant.png unranked.png
          (단계별 아이콘을 쓰면 gold_1.png … 처럼)
  maps/   ascent.png bind.png haven.png split.png lotus.png pearl.png sunset.png corrode.png ...
```

- 파일명은 PRD의 티어 키(`gold_2` 등)·맵 키와 맞춘다.
- 시안의 맵 목록(어센트·바인드·헤이븐·스플릿·로터스·펄·선셋·코로드)은 예시. 실제 맵은 PRD F6-1 `DEFAULT_MAP_POOL` 기준 (어비스, 어센트, 헤이븐, 로터스, 스플릿, 서밋, 선셋). 풀에서 빠진 맵 이미지도 맵 풀 설정 화면용으로 넣어두면 좋다.
- 공개 배포 시 라이엇 공식 이미지는 라이엇 팬 콘텐츠 정책 범위 안에서 쓰고, 사이트 하단에 "Riot Games와 무관한 팬 제작 도구" 문구를 넣는다.

## 6. 시안 ↔ PRD 차이 (구현 시 PRD 기준)

| 항목 | 시안 | PRD (구현 기준) |
|---|---|---|
| 맵 목록 | 바인드·펄·코로드 포함 8개 | PRD F6-1의 `DEFAULT_MAP_POOL` 7개 (어비스, 어센트, 헤이븐, 로터스, 스플릿, 서밋, 선셋) |
| 맵 밴 | `MapBan`: "밴할 맵 2개 · 2/2" | **0~2개** 선택. 카운터는 `N/2`, 0개여도 [맵 랜덤] 활성 |
| 팀 결과 버튼 | `PcHost`: "팀 다시 짜기" | 첫판용 생성. 버튼 문구는 "팀 짜기" |
| 결과 연출 | 정적 결과 화면 | 하이라이트가 칸을 이동하다 멈추는 연출 (PRD F8) |
| 참가자 내 정보 | `Participant`: [수정] 버튼, `PcParticipant`: 왼쪽 수정 폼 | 카드에 [수정] [삭제] 버튼, 수정은 시트(PC는 모달). 삭제는 화면 안 확인 모달 (F3-9) |
| 첫 진입 | 시안 없음 | "이거 나임" 없음. 미등록 기기면 정보 입력 화면만 표시 (F3-6) |

시안과 일치하는 부분: 참가자 체크 없이 멤버 전원(10명)이 팀 짜기 대상, 맵 밴은 방장만 — 시안 그대로 가면 된다.

시안에 없는 화면(첫 진입 정보 입력, 일괄 등록, 맵 풀 설정, 만료된 방, 에러 상태)은 위 토큰·패턴으로 같은 톤에 맞춰 만든다.
